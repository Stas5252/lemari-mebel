# Проверка каталога

Требуется Python 3 и Playwright: `python -m pip install playwright`.
Установите Chromium (`python -m playwright install chromium`) или задайте путь к своему браузеру через `CHROMIUM_PATH`.

Запуск всех проверок: `python -m unittest discover -s tests -v`.
Тесты сами поднимают статический сервер и проверяют поиск, сочетание фильтров, сортировку, просмотр проекта, клавиатуру, переход к калькулятору, мобильную ширину и работу без JavaScript.

Для проверки опубликованного сайта задайте `CATALOG_TEST_URL`. Формы заявок и внешние сообщения не отправляются.
